# TFT docs

This folder is itself an Obsidian vault, so the documentation is dogfooded in both apps.

- [[Specification]] — what TFT implements, its invariants, vault formats, views, commands and
  deliberately deleted features. This is the normative project specification.
- [[Web]] — the Drive-backed web shell, its desktop-parity goal and phase plan.
- [[Web-Rebuild]] — temporary foundation-first rebuild plan and acceptance gates.

The probe transcripts and the measured Obsidian values behind the specification are kept beside
the probes in `tools/obsidian-probe/reference/observed-behavior.md`. Build commands live in the
repository's `CLAUDE.md` and `README.md`.
